# PLOTFLOW brand pack: 井筒に橘

Colors: red #e8351f · olive #43463e · bristol #f6f3ec · ink #15160f

## SVG (resolution-independent)
- `plotflow-crest-stroked.svg`: primary mark. Stroked red; use on dark grounds.
- `plotflow-crest-ink.svg`: flat ink form; use on paper/light grounds, print, seals.
- `plotflow-tachibana-stroked.svg` / `-ink.svg`: plain 橘 (no frame), the
  small-size form for 24–48 px display. Below 24 px use a text glyph.

## PNG (socials, ready to upload)
- `avatar-tachibana-1024.png`: **recommended avatar** (Instagram/Etsy/X).
  Profile photos render tiny; plain 橘 stays legible where the framed
  crest goes muddy.
- `avatar-crest-1024.png`: full crest on olive, for contexts that show
  the avatar large.
- `banner-1500x500.png`: X/Twitter header (lockup, stroked on olive).
- `banner-etsy-1600x400.png`: Etsy shop banner (flat ink on bristol).

Site files (already wired): `/favicon.svg`, `/apple-touch-icon.png`,
`/assets/og.png` (1200×630 share image).

Rules (from the logo spec): the crest is the only red in a lockup; framed
crest never below 48 px; no containers, gradients, or shadows; the
literal * stays in running copy: the crest never replaces punctuation.
